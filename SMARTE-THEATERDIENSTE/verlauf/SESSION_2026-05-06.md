### Phase 7 — Verifikation, dabei zwei Bugs gefunden + behoben

1. **Twitter-Card fiel auf `summary` zurück**, obwohl Layout `summary_large_image` setzt. Ursache: `pageMetadata`-Helper baute ein neues `twitter`-Object ohne `card` → Pro-Page-Twitter überschrieb den Layout-Default. Fix: `card: "summary_large_image"` im Helper. `curl /de/projekt` zeigt jetzt korrekt `summary_large_image`.

2. **`/icon` redirected → 500.** `curl -I /icon` lieferte `307 → /de/icon`, dort `500 InvariantError: client reference manifest for route "/[locale]" does not exist`. Root cause: i18n-Proxy-Matcher `(?!api|_next|_vercel|.*\..*)` matched `/icon` (kein Punkt), redirected zu Locale-Pfad, der für ein Top-Level Convention File nicht existiert. Fix in `src/proxy.ts`: Matcher erweitert um `icon|apple-icon|opengraph-image|twitter-image|manifest` — Top-Level-Convention-Files ohne Extension.

Verifikation nach Fix:
- `pnpm typecheck`, `pnpm lint`, `pnpm build` clean
- `curl /sitemap.xml` → XML mit allen 13 Static-Hrefs × 2 Locales + `xhtml:link rel="alternate"`-Sprachen (de, en, x-default), plus 4 Blog-URLs aus Supabase-Seed (kickoff/erste-pilotpartner × DE/EN)
- `curl /robots.txt` → User-Agent: *, Allow /, Disallow /api/, Sitemap-Pointer
- `curl -I /icon` → 200 OK, Content-Type `image/png`, 528 Bytes (`32×32 RGBA`)
- `curl -I /de/opengraph-image` und `/en/opengraph-image` → 200 OK
- `curl /de` zeigt: title, description, canonical, hreflang de/en/x-default, og:title/url/image/type, twitter:card="summary_large_image"
- `curl /en/contact-persons` → canonical + alternates korrekt mit Slug-Übersetzung
- `curl /de/blog/kickoff-datenraum-kultur` → og:type="article", alternates komplett
- HTML enthält `<link rel="icon" href="/icon?...">` und `<link rel="icon" href="/favicon.ico?..." sizes="256x256">` — beide Icons koexistieren
