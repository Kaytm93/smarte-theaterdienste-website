| ADR-36 | 2026-05-06  | **Satori erlaubt in `ImageResponse` nur die CSS-Display-Werte `flex`, `block`, `contents`, `none`, `-webkit-box`** — `inline-block` führt zu HTTP 500 in Production | Satori (das Engine hinter `next/og`'s `ImageResponse`) ist eine eigenständige CSS-Implementation, kein Browser-CSS. `display: inline-block` wirft beim Rendering einen Pipe-Error (`failed to pipe response`, cause: `Invalid value for CSS property "display"`).
