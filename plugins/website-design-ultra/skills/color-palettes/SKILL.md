# Color Palettes — Production Ready

20 kalibrierte Paletten. Niemals zufällige Hex-Codes erfinden. Eine wählen oder eine neue mit gleicher Disziplin bauen.

## Konstruktions-Regeln (für neue Paletten)

- **Max 1 Akzentfarbe.** Saturation < 80%.
- **5 Töne im Neutral** — Background → Surface → Border → Muted-Text → Text
- **Body-Text-Kontrast min 7:1** (AAA) zum BG
- **UI-Elemente min 4.5:1** (AA)
- **Niemals pure `#000000`** außer Swiss/Print-Heritage
- **Akzentfarbe in Neutral-Tönen leicht tinten** für Harmonie

## Tinted-Shadow-Regel

Shadows niemals pure schwarz `rgba(0,0,0,...)`. Immer zur BG-Hue tinten:

```css
/* Cream-BG */
box-shadow: 0 20px 40px -15px rgba(122, 59, 46, 0.12);

/* Forest-BG */
box-shadow: 0 20px 40px -15px rgba(58, 90, 64, 0.15);

/* Cool-Tech-BG */
box-shadow: 0 20px 40px -15px rgba(15, 23, 42, 0.08);
```

## Output-Format

Wenn du eine Palette einsetzt, definiere sie als CSS-Variablen:

```css
:root {
  --bg:         #0a0a0a;
  --surface:    #171717;
  --border:     #262626;
  --text-muted: #71717a;
  --text:       #fafafa;
  --accent:     #10b981;
}
```

So kann der User später leicht ändern.
